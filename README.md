# RealExecutor — Source Backend

Восстановленный backend-пакет проекта [RealExecutor](https://projectreal.gg/).

Этот репозиторий подготовлен для исследовательской работы над RealExecutor. В
него помещены нативные компоненты, извлечённые из установленной копии
RealExecutor `2.7.0`, и восстановленная production-копия frontend.

## Что находится в репозитории

```text
backend/
└── real-2.7.0/
    ├── Real.exe
    └── bin/
        ├── Real.exe
        ├── Real.dll
        ├── real-mcp.exe
        ├── luau-lsp.exe
        └── Spoofer.exe

```

## Важное уточнение

Название репозитория содержит `SRC`, но оригинальные исходники native backend из
установленного приложения не извлекались. Поэтому содержимое `backend/` — это
восстановленные бинарные артефакты оригинальной версии `2.7.0`, а не заново
написанная реализация и не реконструированный исходный код.

Все шесть компонентов проверены сравнением SHA-256 с файлами в установленной
копии RealExecutor.

## Frontend

В репозиторий добавлена восстановленная production-копия frontend в
`frontend/frontend-root`. Она запускается как статическая копия SvelteKit через
техническую браузерную обвязку и сохраняет оригинальные production-бандлы,
CSS, Monaco, иконки и изображения.

Проверена вкладка `Scripts`: оригинальный `Script Hub` открывается с разделами
`Browse`, `Saved`, `Recent`, источниками и `Filters`. Для browser-only режима
добавлен отдельный минимальный локальный файловый адаптер в `index.html`:
пользовательские локальные файлы хранятся в `localStorage`, а операции
открытия, создания, переименования и удаления не требуют native backend.
Никакие демонстрационные скрипты или вымышленные карточки в репозиторий не
добавляются.

Нативные операции инъекции, запуска скриптов, подмены процессов и работы с
памятью намеренно отключены. Это восстановление интерфейса и безопасных
локальных операций, а не реализация executor-механики.

Запуск frontend:

```powershell
powershell -ExecutionPolicy Bypass -File .\run-frontend.ps1
```

После запуска откройте `http://127.0.0.1:4173/?guest=1`.

При запуске `run-frontend.ps1` поднимается технический transport для
оригинальной Tauri-команды `hub_fetch`. Он делает настоящие GET-запросы к
разрешённым оригиналом источникам и не содержит демо-скриптов или
синтетических карточек.

Transport использует установленный в рабочем Python-окружении пакет `requests`,
поскольку Haxhell отдаёт chunked keep-alive ответ, который стандартный
`urllib` не завершает корректно.

Если внешний источник недоступен или вернул ошибку, интерфейс не подменяет её
тестовыми данными.

## Безопасность и данные пользователя

В репозиторий намеренно не включены DPAPI-хранилище аккаунта, cookies,
WebView2-профиль, кэш, базы данных, ярлыки и журналы установки. Эти файлы
привязаны к конкретному компьютеру и не должны публиковаться.

Используйте пакет только в собственной изолированной исследовательской копии и
только если у вас есть право распространять соответствующие компоненты.
